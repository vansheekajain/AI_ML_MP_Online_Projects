# AI_ML_MP_Online_Projects

A collection of Artificial Intelligence and Machine Learning projects completed as part of academic coursework and personal learning.

## Projects

### 🚀 Lunar Lander RL Agent Training
- Reinforcement Learning project for training an agent to land safely in the Lunar Lander environment.
- Techniques: Reinforcement Learning, OpenAI Gym

---

### 🎬 Movie Recommendation System
- A recommendation system that suggests movies based on user preferences.
- Techniques: Content-Based Filtering, TF-IDF, Cosine Similarity

---

### 🤖 RAG Chatbot
- Retrieval-Augmented Generation (RAG) chatbot for answering questions using custom documents.
- Technologies: Python, LangChain, Vector Database, LLM

---

### 🌐 Render Deployment
- Deployment files and configuration for hosting machine learning and web applications on Render.

---

### 🛒 CartPole
- Reinforcement Learning implementation for solving the CartPole balancing problem.
- Techniques: Q-Learning / Deep Reinforcement Learning

---

## Technologies Used
